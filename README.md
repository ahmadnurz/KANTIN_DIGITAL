# 🍽️ KANTIN DIGITAL

KANTIN DIGITAL adalah aplikasi berbasis web yang dirancang untuk memudahkan proses pemesanan makanan dan minuman di kantin secara digital. Sistem ini memungkinkan pengguna melihat menu, melakukan pemesanan, serta membantu pengelola kantin dalam mengelola transaksi dan data produk secara lebih efisien.

## ✨ Features

* 📋 Menampilkan daftar menu makanan dan minuman
* 🛒 Sistem pemesanan makanan secara online
* 💰 Perhitungan total harga otomatis
* 📦 Manajemen produk makanan dan minuman
* 👤 Sistem login pengguna
* 📊 Dashboard admin
* 📱 Responsive design untuk desktop dan mobile

## 🚀 Installation

### 1. Clone Repository

```bash
git clone https://github.com/ahmadnurz/KANTIN_DIGITAL.git
```

### 2. Masuk ke Folder Project

```bash
cd KANTIN_DIGITAL
```

### 3. Jalankan Server Lokal

Gunakan salah satu software berikut:

* XAMPP
* Laragon
* WAMP

Pindahkan folder project ke:

```bash
htdocs/
```

### 4. Import Database

1. Buka phpMyAdmin
2. Buat database baru
3. Import file `.sql` yang tersedia pada project

### 5. Jalankan Project

Buka browser:

```bash
http://localhost/KANTIN_DIGITAL
```
